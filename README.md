
# HushWoods

*A handcrafted 2D platformer set in a mysterious, glowing forest.*

## Overview

Silent Woods is a solo-developed 2D platformer that immerses players in a mysterious forest filled with environmental puzzles and hostile flora.

Developed entirely in Unity, the project showcases a complete game development workflow, from early design and level creation to gameplay programming, animation, lighting, visual effects, and audio integration.

## Features and Development Highlights

### Gameplay Programming
- Implemented player controls and movement mechanics in C#.
- Developed a dash mechanic.
- Worked with physics and interaction systems.

### Level Design
- Built and tested platforming challenges to match the game's pacing and atmosphere.
- Designed environments around exploration and environmental puzzles.

### Animation
- Integrated character and object animations using Unity Animator.
- Worked with sprite rigging to support character animation.

### Environment Design
- Adapted existing assets to create a cohesive forest landscape.
- Created layered backgrounds.
- Built tile-based terrain using Unity's Tile Palette.

### Lighting and Shadows
- Implemented dynamic 2D lighting and shadow effects.
- Used Unity's Universal Render Pipeline (URP) to establish the glowing forest atmosphere.

### Visual Effects
- Implemented particle systems for atmospheric effects and visual feedback.

### Audio Design
- Integrated ambient soundscapes.
- Added player and enemy sound effects.
- Implemented music transitions to support the game experience.
